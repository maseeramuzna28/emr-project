# EMR Project

Electronic Medical Records (EMR) Management System built using React, TypeScript, FastAPI, and SQLite.

## Features

* Dashboard
* Patient Management
* Doctor Management
* Appointments
* Medical Records
* Billing System
* Emergency Contacts
* AI Disease Prediction

## Tech Stack

### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS

### Backend

* FastAPI
* Python
* SQLite

## Installation

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```
